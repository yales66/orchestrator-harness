# feature-sharding 校准数据

所有常数与乘数都是经验值：每完成一个分片功能，按 SKILL.md「校准回填」实测回填。
每个数值标注来源日期与当时的主力模型；主力模型换代后未在新模型上回填过的条目、以及模型未记录的条目，视为待重测。

## 迭代乘数表

预计总消耗 ≈（启动成本 + 读集成本）× 乘数。

| 风险类别 | 乘数 | 依据（日期，模型） |
|---|---|---|
| 照既有模板抄（CRUD / 相似 router / 相似组件） | ×1.5-2 | 功能 X B/D 路一次交付无返工（2026-07-16） |
| 新基建（repo 首个同类文件、首条同类管线） | ×3-5 | 功能 X A 路：任务条数与 B 路齐平（9 vs 8），实际体量 19 文件 3002 行 vs 2 文件 936 行，且波次 2 仍在返工（2026-07-16） |
| 含未消未知 | 不允许进箱 | 先 spike，或整轨道转人监督独立会话 |
